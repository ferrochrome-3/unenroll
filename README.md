# unenroll.ferrochrome.dev
A website to check what exploits you are able to do on your system<br>Always make sure to double check that the exploit that you have been given is working, most likely by checking crosbreaker or the Ferrochrome server.
## >> Contributing
When you contribute, make sure that you have had atleast 1 tester on a board, and make sure that it isn't a joke post.
Provide proof that you have had a few testers
## >> Submitting issues
When you have noticed that an exploit has stopped working, you may either submit an issue or make a pull request to change it.<br>Provide proof that the exploit no longer works, and we will merge your pull request or delete it.
